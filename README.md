# Zen Flow Timer

Zen Flow Timer is a calm, responsive practice-session workspace built with React, TanStack Start, and TypeScript. It combines sequential countdown timers, flexible break scheduling, timezone-aware calendar tools, persistent local preferences, and an instructor/course showcase in one warm, focused interface.

## Features

### Practice timer

- Personalized onboarding with name, practice goal, timezone, and quick goal presets.
- Create titled timer blocks with minutes and seconds.
- Inline edit, delete, reorder, and reset timer blocks.
- Run blocks sequentially with active and completed states.
- Pause, resume, restart, skip, and reset the session.
- Circular countdown, linear progress, remaining time, and block position feedback.
- Preserve exact running countdowns when blocks are reordered.
- Friendly session-completion notifications.
- Custom session note and total-duration summary.
- Save routines locally in the browser, including completed and active state handling.
- Hide or show session controls and the plan panel from workspace settings.

### Breaks

- Start an immediate break with configurable title, duration, and preset animations.
- Schedule a break to begin after the current timer block.
- Schedule a break after the final block and receive the final completion message after the break finishes.
- Pause the active session while opening break controls.
- Choose from tea, coffee, lunch, relaxation, study, and custom break presets.
- Expand break dialogs for a distraction-free view.
- Animated GIF and video break media from the included public assets.

### Calendar and clock

- Live clock with the user's selected IANA timezone.
- Full timezone-aware calendar and date navigation.
- Add, edit, and delete personal events for a selected day.
- Timezone-scoped local events stored separately from external calendar data.
- Region-aware default holidays generated by timezone rather than persisted static data.
- Upcoming holiday list and visual calendar markers for events and holidays.
- Supported holiday regions include India, United States, Canada, United Kingdom & Ireland, Australia, Europe, and global observances.

### Workspace customization

- Edit the profile name, practice heading, timezone, and heading sizes in a settings sidebar.
- Re-run onboarding from settings.
- Configure separate default heading sizes for profile text and new timer blocks.
- Apply per-block heading sizes while preserving backward-compatible defaults in existing saved data.
- Persist routine, profile, heading, and timezone preferences in browser local storage.
- Responsive layout with reduced-motion support and warm animated UI.

### Instructor showcase

- Create and validate an instructor profile from `/trainer`.
- Add instructor name, role, course name, and description.
- Upload and resize a profile photo in the browser.
- Add custom profile fields and instructor/course details.
- Build an agenda with individual completion tracking.
- Create a class schedule with selectable completion states.
- Choose classic, editorial, elegant, modern, or display typography.
- Customize text scale, heading scale, photo scale, and photo shape.
- Preview the instructor/course showcase full-screen.
- Persist showcase data separately in local storage.

## Getting started

### Practical requirements

- Node.js 20 or newer
- npm or Bun

### Install and run with npm

```bash
npm install
npm run dev
```

### Install and run with Bun

```bash
bun install
bun run dev
```

The development server is provided by Vite. Open the URL printed in your terminal, normally `http://localhost:5173`.

## Local data

The application does not require a backend for routines or showcase data. Browser local storage is used for the following information:

| Storage key | Data |
| --- | --- |
| `timerApp_userName` | Profile name |
| `timerApp_practiceTitle` | Practice heading |
| `timerApp_sessionMessage` | Session note |
| `timerApp_timers` | Timer blocks and routine settings |
| `timerApp_userTimezone` | Selected IANA timezone |
| `timerApp_headingSize` | Profile heading size |
| `timerApp_timerHeadingSize` | Default timer heading size |
| `timerApp_calendarEvents` | Personal timezone-scoped calendar events |
| `timerApp_trainerProfile` | Instructor showcase profile, agenda, and schedule |

Calendar holiday rules are calculated from the selected timezone at runtime. They are not written to local storage, so regional holidays continue to be accurate across years.

## Development notes

- Keep workspace presentation controls in `SettingsSidebar` and `HeadingSizeControl`.
- Keep countdown execution on the existing timer route and in `Timer.tsx` so presentation changes do not reset timers.
- Heading sizes must remain backward-compatible with saved routines and allow per-block overrides.
- Personal calendar date keys use the selected timezone and local wall-calendar date.
- The application should be used without assuming an external calendar account or backend.
- Preserve the existing Lovable configuration in `vite.config.ts`; do not add duplicate TanStack Start plugins.
